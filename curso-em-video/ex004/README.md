# 📝ex004 - Tipos Primitivos

## Descrição
Exercício explorando os tipos primitivos em PHP, como inteiros, floats, booleanos, arrays e objetos.

## Tecnologias
- HTML
- PHP

## Aprendizado
- Uso do `var_dump()` para verificar tipo e conteúdo de variáveis.
- Coerção de tipos (ex: converter string para float).
- Diferença entre valores `true` e `false` ao exibir.
- Estruturas compostas: arrays e objetos.
