# 📝ex005 - Manipulação de Strings

## Descrição
Exercício sobre diferentes formas de manipular strings, concatenação e uso de escape sequences.

## Tecnologias
- HTML
- PHP

## Aprendizado
- Diferença entre aspas simples e duplas no PHP.
- Concatenação de constantes e variáveis.
- Uso de **escape sequences** como `\n`, `\t`, `\\`, `\$` e `\"`.
- Inserir caracteres Unicode com `\u{}`.
