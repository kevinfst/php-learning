# 📝ex002 - Data e Hora

## Descrição
Exibe a data e hora atuais com base no fuso horário configurado.

## Tecnologias
- HTML
- PHP

## Aprendizado
- Definir timezone com `date_default_timezone_set()`.
- Exibir data e hora formatadas usando `date()`.
- Uso de `date("G:i:s T")` para mostrar o timezone em uso.
