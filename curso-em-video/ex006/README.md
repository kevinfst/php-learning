# 📝ex006 - Formulário com PHP

## Descrição
Formulário em HTML que coleta nome e sobrenome e retorna o resultado via PHP.

## Estrutura
- `index.html` → Formulário para entrada de dados.
- `cad.php` → Processa e exibe os dados enviados.
- `style.css` → Estilização da página.

## Tecnologias
- HTML
- CSS
- PHP

## Aprendizado
- Coleta de dados usando formulário (`GET`).
- Operador `??` para tratar valores nulos.
- Integração de HTML + PHP.
- Uso de `javascript:history.go(-1)` para voltar à página anterior.
