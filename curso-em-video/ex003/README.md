# 📝ex003 - Variáveis e Constantes

## Descrição
Demonstra a criação, alteração e exibição de variáveis e constantes em PHP.

## Tecnologias
- HTML
- PHP

## Aprendizado
- Diferença entre **variáveis** (valores mutáveis) e **constantes** (valores fixos).
- Interpolação de variáveis dentro de strings.
