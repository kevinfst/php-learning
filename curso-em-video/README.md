# 📘 Exercícios de **PHP**

Este repositório contém meus exercícios de aprendizado em **PHP**, estudando o curso do canal **Curso Em Vídeo**, organizados por pastas (`ex000`, `ex001`, ...).  
Cada pasta possui seu próprio `README.md` explicando o que foi feito, tecnologias usadas e os aprendizados principais.

---

## 📂 Lista de Exercícios

- [ex000 - Olá, Mundo!](./ex000)  
Primeiro contato com PHP, exibindo uma mensagem simples na tela.

- [ex001 - Dados do Servidor](./ex001)  
Exibição das informações do servidor com `phpinfo()`.

- [ex002 - Data e Hora](./ex002)  
Exibe a data e hora atuais configurando corretamente o timezone.

- [ex003 - Variáveis e Constantes](./ex003)  
Exemplo de criação, alteração e uso de variáveis e constantes em PHP.

- [ex004 - Tipos Primitivos](./ex004)  
Exploração de tipos primitivos como inteiros, floats, booleanos, arrays e objetos.

- [ex005 - Manipulação de Strings](./ex005)  
Trabalhando com concatenação, aspas simples e duplas, escape sequences e Unicode.

- [ex006 - Formulário com PHP](./ex006)  
Formulário HTML integrado ao PHP para coleta e exibição de dados do usuário.
